# تطبيق حديث على Android

هذا المشروع يضم صفحات التطبيق الحالية داخل WebView، ويستخدم منبّهات Android المحلية لحفظ التذكيرات وإرسالها حتى عند إغلاق التطبيق. لا تُرسل التذكيرات إلى خادم.

1. افتح مجلد `android` في Android Studio وانتظر مزامنة Gradle.
2. شغّل التطبيق على هاتف Android أو أنشئ APK من **Build > Build APK(s)**.
3. من الإعدادات أضف وقت ونص كل تذكير، ثم اضغط **السماح بالإشعارات** ووافق على أذونات الإشعارات والمنبّهات.

تعاد جدولة التذكيرات بعد إعادة تشغيل الهاتف أو تغيير الساعة. قد يمنع Android التنبيهات بعد إيقاف التطبيق إيقافاً قسرياً؛ افتح التطبيق مجدداً لتفعيلها.
